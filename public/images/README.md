# Visuels AFRAP

Assets issus des références fournies par AFRAP, redimensionnés et optimisés pour le web. Les documents sources restent dans le dossier local `références/`, hors publication.

- `logo-afrap.webp` : logo transparent fourni, marges transparentes réduites, proportions conservées.
- `accompagnement-domicile.webp` : partie photographique de la couverture du catalogue de septembre 2026, avec son masque de transparence et ses courbes d’origine.
- `formation-cadre.webp` : image 1 du support vierge de septembre 2026.
- `pedagogie-cadre.webp` : image 20 du même support.
- `motif-afrap.webp` : image 27 du même support.
- Le favicon PNG est dérivé du symbole du logo fourni.

Aucun portrait, nom ou présentation personnelle n’est intégré au site. Aucun document source complet n’est mis à disposition dans les fichiers publics.
